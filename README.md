# El viaje de una estrella

Página oficial para descargar **El viaje de una estrella**, de **Sofía Maria Reyes Romero**, en formato EPUB.

## Archivos
- `index.html`: página principal.
- `portada.jpg`: portada mostrada en la página.
- `libro.epub`: versión adaptable del libro.

## Publicar con GitHub Pages
1. Sube los cuatro archivos a la raíz del repositorio `el-viaje-de-una-estrella`.
2. Abre **Settings > Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/ (root)`.
5. Presiona **Save** y espera unos minutos.

La dirección normalmente será:
```text
https://TU-USUARIO.github.io/el-viaje-de-una-estrella/
```
Usa esa dirección para crear el código QR.

## Actualizar el libro
Reemplaza `libro.epub` por la nueva versión conservando exactamente el mismo nombre. Así no tendrás que cambiar el QR.
